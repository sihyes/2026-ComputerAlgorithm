### 파이썬 코드 실행 가이드 (VS Code 환경)

이 코드는 **Visual Studio Code (VS Code)** 환경에서 작성되고 테스트되었습니다. 아래의 단계에 따라 코드를 실행해 주세요.

#### 1. 사전 준비 사항 (필수)
* **Python 설치:** 컴퓨터에 파이썬이 설치되어 있어야 합니다. (터미널에 `python --version`을 입력하여 확인할 수 있습니다.) 혹은 `py --version`
* **Python 확장 프로그램:** VS Code 왼쪽 메뉴의 **확장(Extensions, `Ctrl+Shift+X`)** 탭에서 Microsoft가 제공하는 **'Python'** 확장 프로그램을 검색하여 설치해 주세요.

#### 2. 코드 실행 방법

코드를 실행하는 방법에는 3가지가 있습니다. 가장 편한 방법을 선택해 주세요. (실행 전 `Ctrl + S`를 눌러 파일을 꼭 저장하세요!)

**방법 A: 실행 버튼 사용하기 (가장 간단한 방법)**
1. VS Code에서 실행하려는 파이썬 파일(`.py`)을 엽니다.
2. 화면 우측 상단에 있는 **재생 모양의 아이콘(▷ Run Python File)**을 클릭합니다.
3. 화면 하단의 **터미널(Terminal)** 창에 코드의 실행 결과가 나타납니다.

**방법 B: 단축키 사용하기**
* 파이썬 파일이 열려있는 상태에서 **`Ctrl` + `F5`** (Mac의 경우 `Cmd` + `F5`)를 누르면 파일이 즉시 실행됩니다.

**방법 C: 터미널 창에서 직접 명령어 입력하기**
1. VS Code 상단 메뉴에서 **터미널(Terminal) > 새 터미널(New Terminal)**을 클릭하여 터미널 창을 엽니다.
2. 터미널 창에 아래와 같이 입력하고 `Enter` 키를 누릅니다.
   ```bash
   python 파일명.py
   ```
   *(예시: 파일 이름이 `main.py`인 경우 `python main.py`를 입력합니다.)*

#### 💡 문제 해결 (Troubleshooting)
* 터미널에서 `python` 명령어를 찾을 수 없다는 오류가 발생한다면, `python` 대신 **`python3 파일명.py`** 를 입력해 보세요. (특히 Mac 사용자의 경우)
* 터미널 경로가 현재 파이썬 파일이 있는 폴더인지 확인해 주세요. 경로가 다르다면 `cd 폴더명` 명령어로 이동해야 합니다.
