# Hands-on assignment 1-2: Find minimum number of US postage stamps
Problem definition: To send a letter to my friend, Nate, it costs 140 cents. We have nine postage stamps, each costing: 1500, 1225, 350, 100, 70, 34, 21, 10, 1 cents. 
(Note that stamps are sorted in non-increasing order).

- Step 1 (Generate): Prompt an AI with the exact problem definition above and ask it to "implement a greedy algorithm to find the minimum count of postage stamps needed." Document your prompt and the AI's output code.
- Step 2 (Analyze): Run the AI's code. Report the total number of stamps the AI's greedy algorithm suggests, and state the exact combination of stamps it chose. Analyze the time complexity of this greedy implementation.
-  Step 3 (Critique & Prove): Show that the AI's greedy implementation does NOT provide the optimal solution.
-   Requirement: State the true optimal solution (which you must find manually or by tracing). Explain the logical flaw in the AI's greedy approach -- why does picking the largest local optimum fail to yield the global optimum for this specific set of stamp denominations?

# 1-2. 우표 개수 최소화 (Greedy Algorithm)

문제 정의: 친구에게 편지를 보내는 비용은 140센트입니다. 사용할 수 있는 우표는 [1500, 1225, 350, 100, 70, 34, 21, 10, 1] 센트입니다. (내림차순 정렬됨)

- Step 1 (생성): AI에게 위 문제 정의를 주고 "우표 개수를 최소화하는 그리디(Greedy) 알고리즘을 구현해달라"고 요청하세요. 프롬프트와 코드를 기록합니다.

- Step 2 (분석): AI 코드를 실행하여 그리디 알고리즘이 제시한 총 우표 개수와 조합을 기록하세요. 이 알고리즘의 시간 복잡도를 분석하세요.

- Step 3 (비판 및 증명): AI의 그리디 알고리즘이 최적해(Optimal Solution)가 아님을 증명하세요.
    - 요구사항: 수작업이나 추적을 통해 진짜 최적해를 찾아 제시하세요. 이 특정 우표 단위 세트에서 왜 '현재 가장 큰 단위를 선택하는 지역적 최적해(Local Optimum)' 방식이 전체 최적해(Global Optimum)에 도달하지 못하는지 논리적 결함을 설명하세요.
